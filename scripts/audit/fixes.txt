#   R series lang|form|old key|which|new key[|pos|gender|en|ko]   re-key gloss tokens (form = printed form, lowercase)
#       which: *        every token with this form → old key
#              VERB … : tokens in the audit TSV row(s) with this form / old key whose spaCy pos starts with it
#       new key not in the lexicon yet → a new entry (pos · gender · en · ko; copied from another series when that one has it)
#   E series lang|key|pos|en|ko                                    change one entry's pos / glosses
#
# Re-keyed tokens are also written to scripts/vocab/src/<lang>_occ.txt (series/letter:msg:idx=key) and new lemmas to
# <lang>_tab.txt, so build.py · build_tl.py keep them.
#
