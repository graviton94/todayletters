# 하루의 편지 · 화면 계층과 흐름

화면을 만들 때 이 문서를 기준으로 삼아요. 계층과 뒤로 가기 규칙은 `android/core/.../Routes.kt`,
앱 시작 순서와 도움말은 `Launch.kt`, 설정 범위는 `Settings.kt` 에 코드로 옮겨 두었고 테스트로 지켜요.

## 1. 용어

| 말 | 뜻 | 예 |
|---|---|---|
| 작품 (시리즈) | 한 사람이 쓴 편지 묶음. 원어가 정해져 있어요 | 빈센트 → 테오 (프랑스어), 모차르트 → 아버지 (독일어) |
| 챕터 | 작품을 시기로 나눈 단위. 무료 · 유료 경계도 챕터 단위 | Chapitre II · 아를의 밤 |
| 편지 | 한 통 = 대화방 한 번. 메시지 여러 개로 나뉘어 도착해요 | Lettre XIII |
| 답장 (플레이어블) | 편지를 받은 뒤 하는 학습 화면 | 낱말 맞추기 · 별자리 잇기 · 따라 읽기 · 듣고 쓰기 |
| 앱 글자 언어 | 설정 · 단추 · 도움말 · 큐레이터 노트 · 낱말 뜻풀이. **영어 · 한국어 둘** (폰이 한국어면 한국어, 그 밖에는 영어) | English |
| 읽는 언어 | 말풍선의 작은 줄. **앱 전체에 하나**. 원어 · 영어 · 한국어 어느 것이든 | 한국어 |
| 배우는 언어 | 말풍선의 큰 줄. **작품마다 따로** | 고흐는 프랑스어, 모차르트는 영어 |

모든 편지는 원어 · 영어 · 한국어 세 줄을 늘 갖고 있어요. 읽는 언어와 배우는 언어는 그중 둘을 고르는 것이에요.
앱 글자 언어는 이것과 따로 가요. 그래서 편지 줄은 3 × 3 조합을 모두 지키면서, 번역 · 검수 · 스토어 등록은 영어 · 한국어 두 벌만 하면 돼요.
프랑스어 · 독일어 같은 원어는 "배우는 언어"(그리고 원하면 작은 줄)로만 쓰고, 앱 글자로는 내지 않아요.

## 2. 앱을 켰을 때

기존 두 앱(하루의 성경 인트로 · 하루의 정원 첫 만남)의 흐름을 이어받아요.

```
시스템 시작 화면 (봉랍 아이콘, 바탕은 paper)
  │
  ├─ 그날 첫 실행 ── 봉투 인트로
  │     1. 봉투가 놓이고 소인이 찍혀요 (오늘 날짜 · 편지 속 날짜 "ARLES 9 JUIL 1888")
  │     2. "새 편지 2통" · 봉랍을 눌러 열어요
  │     3. 첫 줄이 타이핑으로 미리 나와요
  │     4. 눌러서 들어가기 (숨 쉬듯 깜빡이는 글자)
  │
  ├─ 같은 날 다시 ── 짧은 인트로: 제목이 한 글자씩 → 눌러서 들어가기
  │
  ├─ 처음 설치 ── 인트로 다음에 처음 소개 (아래 3)
  │
  └─ 편지함 (메인)
```

- **로딩은 따로 두지 않아요.** 콘텐츠 확인 · 구매 복원은 인트로 뒤에서 함께 돌고, 준비가 끝나야 "눌러서 들어가기"가 나타나요 (최소 `motion.loadingMinMs`).
- **건너뛰기:** 아무 데나 누르거나 뒤로 가기 → 바로 입장.
- **인트로 없이 바로:** 폰의 움직임 줄이기가 켜져 있거나, 알림으로 들어올 때 (그 편지 대화방으로 바로).
- 탭할 때마다 가벼운 진동 (설정에서 끌 수 있어요).

## 3. 처음 소개 (첫 설치 한 번)

| 단계 | 화면 | 저장되는 곳 |
|---|---|---|
| 1 | 어떤 언어로 읽을까요? (한국어 · English · 원어). 앱 글자는 폰 언어로 이미 정해져 있고 여기서 함께 바꿀 수 있어요 | 앱 설정 `ui` · `read` |
| 2 | 누구의 편지부터 받을까요? (작품 표지 고르기, 다음 작품은 "곧") | 진행 중인 작품 |
| 3 | 이 작품에서 어떤 언어를 배울까요? (원어 권함) + 말풍선 미리보기 | 작품 설정 `learn` |
| 4 | 답장은 어떻게 쓸까요? · 하루 편지 수 | 작품 설정 `modes` · `lettersPerDay` |
| 5 | 편지가 오면 알려 드릴까요? (알려 주세요 / 괜찮아요) | 알림 권한, 한 번만 물어요 |
| → | 첫 편지 대화방으로 바로. 대화방 도움말이 처음 한 번 저절로 떠요 | |

설정 › 도움 › **소개 다시 보기**는 1~2단계 화면만 다시 보여 주고 아무것도 바꾸지 않아요.

## 4. 화면 트리

```
앱
├─ 0  시작: 시스템 시작 화면 → 인트로 → (처음 소개) ─────────────── 위 2 · 3
│
├─ 1  이름표 (탭) ─ 맨 위 화면에만 [ (?) 도움말 ] [ ⚙ 앱 설정 ]
│   ├─ 편지함 (Inbox) ············ 진행 중인 작품마다 대화방 한 줄, 새 편지 수
│   │    └─ 편지(대화방) 지름길 → 뒤로 가면 편지함
│   ├─ 서재 (Library) ············ 모든 작품 표지 (진행 · 무료 · 곧)
│   │    └─ 2 작품
│   ├─ 단어장 (Words) ············ 작품별로 모은 낱말 → 복습 (낱말 맞추기)
│   └─ 화첩 (Gallery) ············ 받은 그림 → 작품 상세
│
├─ 2  작품 (Series) ─ 표지: 소개 · 등장인물 · 진도 · [ ⚙ 작품 설정 ] · 구매
│   ├─ 작품 설정 ················ 배우는 언어 · 작은 줄 보이기 · 답장 방식 · 하루 편지 수 · 도착 알림
│   ├─ 구매 ···················· 남은 편지 수와 기간을 먼저 보여 줘요 ("편지 78통 · 약 2달 반")
│   └─ 3 챕터 목차 (I ~ V)
│
├─ 3  챕터 (Chapter) ─ 여는 장: 그림 한 점 · 그 시기 배경 노트 · 편지 목록
│   └─ 4 편지
│
├─ 4  편지 = 대화방 (Letter) ─ 메시지가 입력 중 표시와 타이핑으로 도착
│   ├─ 시트: 낱말 카드 · 위치 공유 · 큐레이터 노트 펼침
│   ├─ 대화방 정보 (서랍) ······· 인물 · 타임라인(앞일 가리기) · 그때 세계 · [ 작품 설정 ]
│   ├─ 5 답장 (Play) ··········· 낱말 맞추기 / 별자리 잇기 / 따라 읽기 / 듣고 쓰기
│   │      뒤로 가기는 한 번 물어요: "답장은 나중에 쓸까요?"
│   └─ 편지 완료 (Done) ········· 그림 도착 → 작품 상세 / 다음 편지
│
└─ 겹쳐 뜨는 것 (어디서나): 앱 설정 · 도움말 · 구매 · 알림 권한 묻기
```

### 뒤로 가기

- 계층은 하나예요. `Nav.up()` 이 정한 부모로 올라가요.
- 편지함에서 들어간 대화방은 편지함으로, 서재에서 들어간 대화방은 챕터로 돌아가요.
- **알림으로 바로 들어와도** 길을 잃지 않아요. `Nav.trail()` 로 편지함까지의 길을 만들어 두기 때문이에요.
- 이름표의 맨 위 화면에서 뒤로 가면 편지함으로 가고, 편지함에서 한 번 더 누르면 앱을 나가요.
- 답장 중에는 바로 나가지 않고 한 번 물어요. 녹음 · 재생 중일 때도 같아요.
- 편지는 메시지 단위로 진도가 저장돼요. 중간에 나가도 그 자리에서 다시 이어요.

## 5. 설정은 어디서, 무엇을

| 범위 | 여는 곳 | 항목 |
|---|---|---|
| **앱 설정** (모든 작품) | 이름표 맨 위 화면의 ⚙ | 앱 글자 언어(English / 한국어) · 읽는 언어(작은 줄) · 테마(시스템 / 라이트 / 다크) · 글자 크기(보통 / 크게) · 타이핑(차분하게 / 빠르게 / 바로 보기) · 소리 · 진동 · 알림 기본 시각 · 사용법 다시 보기 · 소개 다시 보기 · 구매 복원 · 작품 출처와 라이선스 |
| **작품 설정** (작품마다) | 작품 표지의 ⚙, 대화방 정보 서랍, 처음 소개 3~4단계 | 배우는 언어 (원어 · 영어 · 한국어 중 읽는 언어를 뺀 것) · 작은 줄 보이기 · 답장 방식 · 하루 편지 수 · 도착 알림 |
| **대화방 빠른 토글** | 대화방 위쪽 | "작은 줄 가리기" 단추 · 메시지 길게 눌러 바로 보기. 바꾼 값은 작품 설정에 저장돼요 |

정해 둔 규칙은 다음과 같아요.

- **배우는 언어는 작품마다 따로예요.** 고흐는 프랑스어로 두고, 모차르트는 영어로 둘 수 있어요.
- **읽는 언어를 바꿔서 어느 작품의 배우는 언어와 같아지면,** 그 작품만 권하는 언어(원어)로 옮기고 한 줄 알림을 띄워요 (`Langs.afterReadChange`).
- **폰의 움직임 줄이기가 켜져 있으면** 타이핑은 늘 바로 보기예요.
- **테마는 사용자 설정을 따라요.** 편지의 시간대로 화면이 바뀌지 않아요. 편지의 시간은 소인과 날짜 글자로만 보여 줘요.

## 6. 도움말 (?)

하루의 성경의 코치 마크 방식을 그대로 써요.

- 화면마다 도움말 묶음이 있어요 (`coach_<화면>_<항목>`). 처음 그 화면에 왔을 때, 화면이 조용하면 한 번 저절로 떠요. 조용하다는 건 시트가 열려 있지 않고 타이핑 · 재생 중이 아니라는 뜻이에요.
- 맨 위 줄의 **(?)** 를 누르면 그 화면 것만 다시 보여 줘요 (`Coach.again`).
- 설정 › 도움 › **사용법 다시 보기**는 전부 처음 상태로 돌려요 (`Coach.reset`).
- 표현 방식: 바탕을 어둡게 덮고 대상만 구멍을 내서 금빛 테를 둘러요. 말풍선에는 "건너뛰기 · n / N · 다음 ›" 가 있어요.
- 마지막 말풍선에는 "막히는 곳이 있나요? 의견 보내기 ›" 를 둬요.
- (?) 글자 크기는 폰 글꼴 배율과 상관없이 고정이고, 읽어 주기 이름은 "이 화면 도움말"이에요.

| 화면 id | 처음 보여 줄 것 |
|---|---|
| `inbox` | 대화방 한 줄 = 작품 하나 · ⚙ 앱 설정 위치 |
| `library` | 작품 표지 · 무료 챕터 표시 |
| `series` | 작품 설정(⚙) · 목차 |
| `room` | 큰 줄 / 작은 줄 · 낱말 누르기 · 작은 줄 가리기 · 대화방 정보 |
| `play_constellation` | 낱말을 차례로 누르면 별자리처럼 이어져요 |
| `play_aloud` | 원어 듣기 → 녹음 → 보내기 (MVP 는 녹음한 것만으로 완료) |
| `words`, `gallery` | 복습 시작 · 그림 누르기 |

## 7. 움직임과 손맛

- **타이핑:** 입력 중 표시(`typingDotsMs`) → 글자가 나타남(`typeCharMs` × `typeChunk`) → 다음 메시지까지 쉼(`betweenMessagesMs`). 아직 안 나온 글자는 투명하게 자리를 잡아 두어서 줄이 흔들리지 않아요 (하루의 정원 `TypedText` 방식).
- **한국어 줄바꿈:** 어절 단위 (`LineBreak.WordBreak.Phrase`).
- **팝업:** 모든 팝업과 시트는 같은 등장 하나만 써요 (투명 → 보임, 0.94 → 1).
- **진동:** 봉랍 열기 · 별 잇기 한 칸 · 답장 보내기에만.
- **움직임 줄이기:** 인트로 건너뜀, 타이핑 바로 보기, 반짝임 멈춤.
- **글자 크기:** 두 단계(보통 · 크게). 폰 글꼴 배율은 `ratio.systemFontMax` 까지만 따라가요.
