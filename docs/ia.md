# 언어 미술관 · 화면 계층과 흐름

화면을 만들 때 이 문서를 기준으로 삼아요. 계층과 뒤로 가기 규칙은 `android/core/.../Routes.kt`,
앱 시작 순서와 도움말은 `Launch.kt`, 설정 범위는 `Settings.kt` 에 코드로 옮겨 두었고 테스트로 지켜요.

## 1. 용어

| 말 | 뜻 | 예 |
|---|---|---|
| 작품 (시리즈) | 한 사람이 쓴 편지 묶음. 원어가 정해져 있어요 | 빈센트 → 테오 (프랑스어), 모차르트 → 아버지 (독일어) |
| 챕터 | 작품을 시기로 나눈 단위. 무료 · 유료 경계도 챕터 단위 | Chapitre II · 아를의 밤 |
| 편지 | 한 통 = 대화방 한 번. 메시지 여러 개로 나뉘어 도착해요 | Lettre XIII |
| 답장 (플레이어블) | 편지를 받은 뒤 하는 학습 화면 | 낱말 맞추기 · 별자리 잇기 · 따라 읽기 · 듣고 쓰기 |
| 앱 글자 언어 | 설정 · 단추 · 도움말 · 큐레이터 노트 · 낱말 뜻풀이. **영어 · 한국어 둘** (폰이 한국어면 한국어, 그 밖에는 영어) | English |
| 읽는 언어 | 말풍선의 작은 줄. **앱 전체에 하나**. 원어 · 영어 · 한국어 어느 것이든 | 한국어 |
| 배우는 언어 | 말풍선의 큰 줄. **작품마다 따로** | 고흐는 프랑스어, 모차르트는 영어 |

모든 편지는 원어 · 영어 · 한국어 세 줄을 늘 갖고 있어요. 읽는 언어와 배우는 언어는 그중 둘을 고르는 것이에요.
앱 글자 언어는 이것과 따로 가요. 그래서 편지 줄은 3 × 3 조합을 모두 지키면서, 번역 · 검수 · 스토어 등록은 영어 · 한국어 두 벌만 하면 돼요.
프랑스어 · 독일어 같은 원어는 "배우는 언어"(그리고 원하면 작은 줄)로만 쓰고, 앱 글자로는 내지 않아요.

## 2. 앱을 켰을 때

```
시스템 시작 화면 (봉랍 아이콘, 바탕은 paper)
  │
  ├─ 입구 (매번) ── 언어 미술관 입구: 내가 모은 그림이 천천히 바뀌며 지나가요 (모을수록 풍성해지는 보상).
  │                 모은 그림이 셋보다 적으면 그날의 작품 한 점. 뒤에서 편지 · 카드를 불러 두고 ‘입장’
  │
  ├─ 처음 설치 ── 환영 한 장 → 서재 (튜토리얼, 아래 3)
  │
  └─ 서재 (메인) → 작품 카드 → 짧은 전환 (저절로 들어감) → 오늘
```

- **인트로 없이 바로:** 언어를 바꿔 화면을 다시 그릴 때 (`Launch.plan(deepLink)`). 알림으로 들어오면 그 작품의 오늘부터.
- 탭할 때마다 가벼운 진동 (설정에서 끌 수 있어요).

## 3. 처음 설치의 튜토리얼 (한 번, `core/Launch.kt` 의 `Tutorial`)

| 단계 | 화면 | 저장되는 곳 |
|---|---|---|
| 1 | 입구 | |
| 2 | 환영: “첫 방문을 환영해요. 우선, 처음이니 제 친구 빈센트 반 고흐와 함께 연습해 봐요.” | `onboarded` |
| 3 | 서재: 빈센트 카드를 금빛 테로 강조, **그 카드 안에서** 배울 말을 고르고 ‘첫 편지 받기’ | 작품 설정 `learn` |
| 4 | 편지 I: 걸음마다 처음 들어갈 때 **한 줄 안내** (읽기 · 낱말 맞추기 · 따라 읽기 “녹음만 해도 통과예요” · 답장 · 그림 산책) | `guide_seen` |
| 5 | 편지 완료 위에 “이제 혼자서도 괜찮아요” → 튜토리얼 끝 | `tutorial_done` |

- 튜토리얼이 끝나면 **어느 작품에서도 도움말이 저절로 뜨지 않아요.** 화면 도움말은 (?) 로만 (`Coach.due(..., auto = false)`).
- 다른 작품에 처음 들어갈 때는 **배울 말 고르기 시트 하나** → 바로 편지 I. 프롤로그는 목차에서 언제든 (저절로 띄우지 않음).
- 예전 사용자: 편지를 한 통이라도 마쳤으면 튜토리얼은 끝난 것으로 봐요.
- 설정 › 도움 › **사용법 다시 보기**: 화면 도움말을 처음 상태로, 편지 걸음의 한 줄 안내도 다시 한 번.

## 4. 화면 트리

```
앱
├─ 0  시작: 입구 → (처음 설치: 환영) ──────────────────────────── 위 2 · 3
│
├─ 1  서재 (Library) ─ [ (?) ] [ ⚙ 앱 설정 ] · 전체 기록 · 작품 카드 (튜토리얼 중이면 첫 카드 강조)
│   ├─ 내 기록 · 전체 (Overall)
│   └─ 짧은 전환 (Enter, 저절로) → (처음이면 배울 말 시트 Welcome → 편지 I) → 2
│
├─ 2  작품 안 이름표 ─ 맨 위 화면에만 [ (?) ] [ ⚙ ]
│   ├─ 오늘 (Inbox) = 오늘의 여정 (`core/Journey.kt`)
│   │    I   오늘의 편지 ── 걸음 점 (읽기 · 낱말 · 따라 읽기 · 답장 · 그림, 건너뛴 걸음은 빈 점)
│   │    II  오늘의 복습 ── 이 작품 카드만 한 판 (뜻 → 빈칸 → 듣고 쓰기), "답한 수 / 이 판의 문제 수"
│   │    III 여정 완료 ─── 보너스 화폐 + 오늘 편지의 그림이 갤러리에 (하루 한 번)
│   │    └─ 전체 편지 목록 (목차) · 편지 n / N
│   ├─ 복습 (Words) ······ 이 작품 카드 여섯 칸 · 오늘의 복습 · 기억 확인 · 자유 연습 (기록됨) · 내 구절 · 다시 하기 (건너뛴 걸음) · 모은 낱말
│   ├─ 갤러리 (Gallery) ·· 편지의 그림 (산책) · 이달의 전시 · 나의 도록 · 희귀도 칸 (화폐로 고르기)
│   └─ 이정표 (Milestones) 메달 · 이번 주 · 일요일 낭독회 · 화폐 쓰기 (쉼표 · 미리 열기 · 작품 고르기 · 액자 · 카드 테두리)
│
├─ 3  목차 (Series) ─ 프롤로그 · 챕터 I~ · 맺음말 · 도록 · [ ⚙ 작품 설정 ]
│   └─ 챕터 (Chapter) ─ 편지 목록 (건너뛴 걸음이 있으면 “건너뛴 걸음 n · 다시 하기”)
│
├─ 4  편지 = 대화방 (Letter) ─ 처음 열면 도착 한 장 (위에 그림 · 아래에 첫 줄과 번역)
│   ├─ 걸음 (Play) ········ 낱말 맞추기 / 따라 읽기 (한 문장, 녹음만 해도 통과) / 답장 (별자리 잇기)
│   │      걸음마다 “건너뛰기”. 건너뛴 걸음은 편지 목록 · 대화방 걸음 목록 · 복습 탭에서 “다시 하기”
│   │      낭독이 없는 편지는 따라 읽기 없이 (`Plays.forLetter`)
│   ├─ 대화방 정보 (RoomInfo) · 그림 산책 (Artwork, 그림이 기기에 있을 때만 점)
│   ├─ 따라 읽기 전체 (Shadow) · 봉인 (Seal: 낱말을 다 떠올리고 따라 읽기 별 하나 이상)
│   └─ 편지 완료 (Done) ········ 그림 도착 · 한 걸음 체크 (건너뛴 것은 ‘나중에’) · 다음 편지
│
└─ 겹쳐 뜨는 것 (어디서나): 앱 설정 · 도움말 (?) · 보상 순간 · 낭독 받기
```

### 뒤로 가기

- 계층은 하나예요. `Nav.up()` 이 정한 부모로 올라가요 (`core/Routes.kt`).
- 오늘에서 들어간 대화방은 오늘로, 목차에서 들어간 대화방은 챕터로 돌아가요.
- 이번 주 · 낭독회 → 이정표, 이달의 전시 · 도록 → 갤러리, 프롤로그 → 목차, 복습 한 판 → 복습.
- **알림으로 바로 들어와도** 길을 잃지 않아요. `Nav.trail()` 로 서재까지의 길을 만들어 두기 때문이에요.
- 이름표의 맨 위 화면에서 뒤로 가면 서재로, 서재에서 한 번 더 누르면 앱을 나갈지 물어요.
- 걸음 중에는 바로 나가지 않고 한 번 물어요. 녹음 · 재생 중일 때도 같아요.
- 편지는 메시지 단위로 진도가 저장돼요. 중간에 나가도 그 자리에서 다시 이어요.

### 보상 (`core/Rewards.kt`)

- 화폐는 **오늘의 여정에서 실제로 한 걸음**으로 모여요: 편지 마치기 · 편지 걸음 (건너뛰지 않은 것) · 오늘의 복습에서 맞힌 낱말 · 여정 완료. 그리고 배움의 이정표 (봉인 · 혼자 읽기 · 메달 · 전시 · 낭독회).
- 자유 연습 · 기억 확인은 기록만 되고 화폐는 없어요.
- 화폐로는 갤러리 작품 고르기 · 액자 · 카드 테두리 (작품마다) · 다음 편지 미리 열기 · 쉼표만 사요. 배움은 늘 무료.

## 5. 설정은 어디서, 무엇을

| 범위 | 여는 곳 | 항목 |
|---|---|---|
| **앱 설정** (모든 작품) | 이름표 맨 위 화면의 ⚙ | 앱 글자 언어(English / 한국어) · 읽는 언어(작은 줄) · 테마(시스템 / 라이트 / 다크) · 글자 크기(보통 / 크게) · 타이핑(차분하게 / 빠르게 / 바로 보기) · 소리 · 진동 · 알림 기본 시각 · 사용법 다시 보기 · 소개 다시 보기 · 구매 복원 · 작품 출처와 라이선스 |
| **작품 설정** (작품마다) | 작품 표지의 ⚙, 대화방 정보 서랍, 배울 말 시트 · 서재 튜토리얼 카드 | 배우는 언어 (원어 · 영어 · 한국어 중 읽는 언어를 뺀 것) · 작은 줄 보이기 · 답장 방식 · 하루 편지 수 · 도착 알림 |
| **대화방 빠른 토글** | 대화방 위쪽 | "작은 줄 가리기" 단추 · 메시지 길게 눌러 바로 보기. 바꾼 값은 작품 설정에 저장돼요 |

정해 둔 규칙은 다음과 같아요.

- **배우는 언어는 작품마다 따로예요.** 고흐는 프랑스어로 두고, 모차르트는 영어로 둘 수 있어요.
- **배우는 언어는 언제든 바꿔요** (서재 카드의 작은 단추 · 시리즈 안 머리 · 작품 설정). **진도는 언어마다 따로** 저장돼요 (읽은 편지 · 낱말 카드 · 오늘의 할 일). 진도 열쇠는 `vincent` (원어) · `vincent@en` · `vincent@ko` (`core/Spaces.kt`), 처음 바꿀 때 한 번 알림.
- **읽는 언어를 바꿔서 어느 작품의 배우는 언어와 같아지면,** 그 작품만 권하는 언어(원어)로 옮기고 한 줄 알림을 띄워요 (`Langs.afterReadChange`).
- **폰의 움직임 줄이기가 켜져 있으면** 타이핑은 늘 바로 보기예요.
- **테마는 사용자 설정을 따라요.** 편지의 시간대로 화면이 바뀌지 않아요. 편지의 시간은 소인과 날짜 글자로만 보여 줘요.

## 6. 도움말 (?)

하루의 성경의 코치 마크 방식을 쓰되, **저절로는 뜨지 않아요** (튜토리얼의 한 줄 안내가 그 몫).

- 화면마다 도움말 묶음이 있어요 (`coach_<화면>_<항목>`). 맨 위 줄의 **(?)** 를 누르면 그 화면 것만 보여 줘요 (`Coach.again` → `asked`).
- 설정 › 도움 › **사용법 다시 보기**는 전부 처음 상태로 돌리고 편지 걸음의 한 줄 안내를 다시 한 번 보여 줘요.
- 표현 방식: 바탕을 어둡게 덮고 아래에서 카드. 카드에는 "건너뛰기 · n / N · 다음 ›" 가 있어요.
- (?) 글자 크기는 폰 글꼴 배율과 상관없이 고정이고, 읽어 주기 이름은 "이 화면 도움말"이에요.

| 화면 id | (?) 로 보여 줄 것 |
|---|---|
| `inbox` | 오늘의 여정 · ⚙ 앱 설정 위치 |
| `library` | 작품 표지 · 배우는 말 단추 |
| `series` | 작품 설정(⚙) · 목차 |
| `room` | 큰 줄 / 작은 줄 · 낱말 누르기 · 작은 줄 가리기 · 대화방 정보 |
| `play_aloud` | 원어 듣기 → 녹음 → 마치기 (녹음만 해도 통과) |
| `words`, `gallery`, `milestones` | 복습 시작 · 그림 누르기 · 메달 |

## 7. 움직임과 손맛

- **타이핑:** 입력 중 표시(`typingDotsMs`) → 글자가 나타남(`typeCharMs` × `typeChunk`) → 다음 메시지까지 쉼(`betweenMessagesMs`). 아직 안 나온 글자는 투명하게 자리를 잡아 두어서 줄이 흔들리지 않아요 (하루의 정원 `TypedText` 방식).
- **한국어 줄바꿈:** 어절 단위 (`LineBreak.WordBreak.Phrase`).
- **팝업:** 모든 팝업과 시트는 같은 등장 하나만 써요 (투명 → 보임, 0.94 → 1).
- **진동:** 봉랍 열기 · 별 잇기 한 칸 · 답장 보내기에만.
- **움직임 줄이기:** 인트로 건너뜀, 타이핑 바로 보기, 반짝임 멈춤.
- **글자 크기:** 두 단계(보통 · 크게). 폰 글꼴 배율은 `ratio.systemFontMax` 까지만 따라가요.

| 2 | 작품 표지 · 목차 · 구매 | 루트 |
| 3 | 챕터 여는 장 | 흐름 1 |
