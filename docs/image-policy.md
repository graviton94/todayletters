# 이미지 사용 원칙 (언어 미술관)

공개본: https://graviton94.github.io/todayletters/terms/ (이 문서와 같은 내용을 유지)

## 원칙
1. **우리가 그린 그림은 쓰지 않는다.** 공공 영역 원작의 이미지만 쓴다. (UI 의 선 · 도형 · 활자 장식은 그림이 아님)
2. **기본 (1단계):** 소장처가 상업 이용을 포함해 허가 없이 쓸 수 있다고 직접 밝힌 이미지 (CC0 · Open Access · Public Domain 표시).
   - 지금 쓰는 곳: 메트로폴리탄 미술관, 시카고 미술관, 미국 국립미술관, 로스앤젤레스 카운티 미술관, 세인트루이스 미술관, 예일대 미술관, 게티, 미니애폴리스, 1914년판 편지집 (archive.org).
3. **예외 (2단계, PD-Art):** 꼭 필요한 대표작만. 아래를 모두 만족할 때.
   - 작가 사후 70년이 지난 **평면** 작품 (회화 · 소묘 · 판화)
   - 위키미디어 공용에 PD-Art (공공 영역 미술품의 충실한 복제) 로 공개된 파일
   - 미술관 웹사이트에서 직접 받지 않는다 (그 약관에 동의하지 않음)
   - 키트 데이터에 `"exception": "pd-art"` 와 위키미디어 파일 주소를 적어 내부 기록으로 둔다. 앱 화면에는 ‘예외’ 표시를 하지 않는다 (2026-10-10 결정: 사용자는 알 필요가 없고, 권리 문의는 공식 연락 경로로 받는다)
   - 근거: Bridgeman v. Corel (미국 1999), EU 지침 2019/790 제14조, 한국 저작권법의 창작성 요건
4. **쓰지 않음:** 입체 작품 사진, 저작권이 남은 작품, 소장처가 비상업으로 제한한 파일을 그 사이트에서 받아 쓰는 것.
